# v2.3 Canonical Source Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从 v2.2.0 EPUB 确定性恢复可审查的 104 章 Markdown、manifest 和审计基线，为六章压缩试点提供安全输入。

**Architecture:** 以 EPUB 的 `package.opf` 和 XHTML 为权威结构，使用纯 Python 标准库完成解析、Markdown 序列化和资源复制。结构验证与审计共用 manifest，生成物只由命令生成，不手工维护；同版本 TXT 只参与字符总量和章节边界校对。

**Tech Stack:** Python 3.12 标准库、`unittest`、GNU Make、JSON、Markdown、EPUB/XHTML。

**Spec:** `docs/superpowers/specs/2026-08-20-v2.3-revision-design.md`

## Global Constraints

- 保留 10 卷、104 章和 1–104 原编号；本子项目不得压缩或改写正文。
- EPUB XHTML 是恢复来源；TXT 是校对基准。
- 转换必须确定性：相同输入重复运行得到逐字节相同的 Markdown 和 manifest。
- 不新增第三方 Python 依赖。
- 图片路径统一指向 `book/assets/`，不得遗失 XHTML 中实际引用的资源。
- manifest 每章必须包含 `id`、`volume`、`part`、`title`、`source`、`level`、`volatile_facts`、`reference_links`。
