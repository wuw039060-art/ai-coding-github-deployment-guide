# v2.3 Six-Chapter Reduction Pilot Implementation Plan

> **For Codex:** Execute this plan inline, task by task. Keep `codex/v2.3-source-recovery` intact as the recovery baseline and commit only on `codex/v2.3-six-chapter-pilot`.

**Goal:** Rewrite chapters 1, 19, 40, 54, 70, and 91 to 55%–60% of their recovered size while preserving their conceptual value and moving operational detail into thematic references.

**Architecture:** Separate immutable recovery fidelity from editorial verification. Add a pilot validator driven by explicit chapter baselines, then rewrite the six chapters against a shared narrative template and four cross-book reference documents. The frozen v2.2 audit remains the comparison baseline.

**Tech Stack:** Python 3 standard library, Markdown, `unittest`, Make.
